# Project Summary

Healthcare Agent Ops Lab is a synthetic review and eval workspace for healthcare
AI agent behavior.

## Hiring Signal

This project is meant to demonstrate:

- Healthcare workflow judgment.
- AI agent behavior review.
- Source grounding and evidence auditability.
- Safety gating for high-risk workflows.
- PHI minimization and escalation discipline.
- Assertion-based eval thinking.
- Product-facing documentation and verification.

## Best Resume Bullet

Built a synthetic Healthcare Agent Ops Lab to evaluate AI agent behavior across
benefits, billing, intake, prior authorization, and clinical-trial navigation
workflows, including source evidence records, safety gates, human review
controls, local review persistence, exportable review JSON, and assertion-based
evals.

## Outreach Blurb

I’m coming from clinical/regulatory operations and building toward healthcare AI
agent development. I made this small eval/review lab to show how I think about
source grounding, escalation, PHI boundaries, and human oversight before an agent
is trusted in a regulated workflow.
